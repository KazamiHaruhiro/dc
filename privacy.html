Privacy Policy

Last updated: 10 November 2026

1. Summary

Drive Collector is a private, single-operator tool. It accesses Google Drive data only for the account that authorises it. No data is collected from, or shared with, anyone else.

2. What data is accessed

DataWhyWhere it goes
File and folder metadata (name, size, ID, checksum, creation date, owner) To list, verify, de-duplicate and rename the owner's own files Processed in memory on the operator's own servers; not transmitted to any third party
File contents (downloaded only when necessary, e.g. to verify two copies are identical) Integrity verification Same as above
OAuth refresh token To keep the authorisation valid without repeated sign-in Stored on the operator's own servers with restricted file permissions

3. What is NOT done with the data

  • No data is sold, rented, or shared with third parties.
  • No data is used for advertising or profiling.
  • No data is transferred to any party other than Google's own Drive API endpoints.
  • No data belonging to anyone other than the authorising account owner is accessed.

4. Google API Services User Data Policy

Drive Collector's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Drive scope data is used solely to provide the file-management functionality described above; it is not used for advertising and is not transferred to others except as necessary to provide that functionality, to comply with applicable law, or as part of a merger/acquisition with prior notice.

5. Storage and security

  • OAuth tokens are stored only on servers controlled by the operator.
  • Access to those servers is restricted to the operator (SSH key / password).
  • Tokens can be revoked at any time by the account owner.

6. Retention and deletion

Token data is kept only while the tool is in use. Revoking the application's access in the Google Account (Security → Third-party apps with account access) immediately and permanently stops all access. Metadata copies used for verification may be retained locally until no longer needed, and are deleted on request.

7. Children's privacy

The tool is not directed at children and does not knowingly process data from children.

8. Changes

This policy may be updated; the "last updated" date above will change accordingly.
