Privacy Policy

Last updated: 10 November 2026

1. Summary

Drive Collector is a private, single-operator application. It accesses Google Drive data only for the account that authorises it. No data is collected from, or shared with, anyone else.

2. What data is accessed, and why

DataPurposeWhere it is processed
File and folder metadata — name, size, file ID, checksum, creation date, owner To list, verify, de-duplicate and rename the operator’s own files In memory on the operator’s own servers; never sent to a third party
File contents — downloaded only when needed, for example to confirm two copies are identical Integrity verification Same as above
OAuth refresh token To keep the authorisation valid without repeated sign-in Stored on the operator’s own servers with restricted file permissions

3. What is not done with the data

  • No data is sold, rented, published or shared with third parties.
  • No data is used for advertising, profiling or credit assessment.
  • No data is transferred anywhere other than Google’s own API endpoints.
  • No data belonging to any person other than the authorising account owner is accessed.

4. Google API Services User Data Policy

Drive Collector’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Drive-scope data is used solely to provide the file-management functionality described above. It is not used for advertising, and is not transferred to others except as necessary to provide that functionality, to comply with applicable law, or as part of a merger or acquisition with prior notice.

5. Storage and security

  • OAuth credentials are stored only on servers controlled by the operator.
  • Access to those servers is limited to the operator and protected by server authentication.
  • Tokens and derived data are held with restricted file permissions.
  • Authorisation can be revoked at any time by the account owner.

6. Retention and deletion

Authorisation data is retained only while the tool is in use. Revoking the application’s access (Google Account → Security → Third-party apps with account access) immediately and permanently ends all access. Local metadata copies used for verification are deleted once they are no longer needed, and on request.

7. Children’s privacy

The application is not directed at children and does not knowingly process children’s data.

8. Changes to this policy

This policy may be updated from time to time; the “last updated” date at the top will change accordingly.

9. Contact

Requests and questions can be raised through the project’s issue tracker: github.com/KazamiHaruhiro/dc/issues
